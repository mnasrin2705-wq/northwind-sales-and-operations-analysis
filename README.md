# Northwind Sales & Operations Analysis Using SQL

## Project Overview

This project analyzes the Northwind sales and operations database using **MySQL** to uncover insights related to sales performance, customers, products, employees, and shipping operations.

The analysis uses multiple related tables and SQL techniques to answer practical business questions and demonstrate data analyst skills in data aggregation, joins, filtering, ranking, date-based analysis, and business insight generation.

## Project Objectives

The main objectives of this project are to:

* Analyze overall sales and order performance
* Identify top-performing product categories and products
* Analyze customer revenue, order frequency, and average order value
* Examine employee-level sales performance
* Evaluate shipping performance and freight costs
* Identify trends in sales over time
* Generate actionable business insights from relational data

## Tools & Technologies

* **Database:** MySQL
* **SQL Environment:** MySQL Workbench
* **Dataset:** Northwind Database
* **Version Control:** GitHub
## Database Structure

The Northwind database consists of seven related tables:

| Table           | Purpose                                                    |
| --------------- | ---------------------------------------------------------- |
| `customers`     | Customer information                                       |
| `orders`        | Order-level information                                    |
| `order_details` | Products, quantities, prices, and discounts for each order |
| `products`      | Product information and pricing                            |
| `categories`    | Product category information                               |
| `employees`     | Employee information                                       |
| `shippers`      | Shipping company information                               |

### Key Relationships

* `orders.customerID` → `customers.customerID`
* `orders.employeeID` → `employees.employeeID`
* `orders.shipperID` → `shippers.shipperID`
* `order_details.orderID` → `orders.orderID`
* `order_details.productID` → `products.productID`
* `products.categoryID` → `categories.categoryID`

These relationships were used to combine information across tables and perform business-level analysis.

## Key Findings

### Sales Performance

* Total sales were **474,912.09** across **809 orders**.
* The average order value was **572.18**.
* **Beverages** was the highest-revenue product category with **112,589.27** in sales.
* **Côte de Blaye** was the highest-revenue product, generating **66,520.58**.
* **Chang** was the highest-volume product with **1,027 units sold**, demonstrating that sales volume and revenue contribution can differ significantly.

### Customer Insights

* **QUICK-Stop** was the highest-revenue customer, generating **42,383.98**.
* **Save-a-lot Markets** placed the highest number of orders with **31 orders**.
* **Simons bistro** had the highest average order value at **2,114.44**.
* Customer value varied across revenue, order frequency, and average order value, showing the importance of evaluating customers from multiple perspectives.

### Employee Performance

* **Margaret Peacock** was associated with the highest sales at **90,418.43**.
* Sales performance varied considerably across employees.

### Shipping & Operations

* The average time from order to shipment was **8.49 days**.
* **772 orders** were shipped on or before the required date, while **37 orders** were shipped late.
* Total freight costs were **63,955.02**, with an average freight cost of **79.05** per order.
* **42 orders** had freight costs higher than their order value, highlighting potentially unusual or inefficient shipping cases that may warrant further investigation.
* **United Package** handled the highest number of orders among the three shippers, with **315 orders**.

### Product Portfolio

* **8 of 77 products** were marked as discontinued.
* Discontinued products still generated measurable sales in the dataset, with **Thüringer Rostbratwurst** generating the highest revenue among them at **38,769.40**.

### Time-Based Insights

* **2014** recorded the highest sales in the available dataset at **229,854.34**, along with the highest order count of **408**.
* The dataset covers **July–December 2013**, the full year **2014**, and **January–May 2015**.
* Therefore, 2013 and 2015 totals should not be interpreted as full-year performance comparisons.

## Data Limitations

The Northwind dataset does not cover complete calendar years for all periods. The available order data begins in **July 2013** and ends in **May 2015**.

Therefore:

* 2013 represents a partial year.
* 2014 represents a complete year.
* 2015 represents a partial year.

Year-wise comparisons should therefore be interpreted in the context of the available data period rather than as complete annual performance comparisons.
